# SDK 只提供平台 API 出站调用机制

WeChatDeveloper 2.0 只负责微信与支付宝官方 API 的配置、认证、请求编码、传输、签名验签、可信错误和流处理，不复制退款、账号资料等业务端点。

通知处理、消息加解密、授权页面、客户端调起、业务请求体加解密、幂等和状态机也不属于调用层。它们不会占用 API 目标或扩展平台通道接口。

## 影响

- 新官方业务端点直接使用官方路径或方法与请求体。
- 只有新的报文协议形态才扩展 SDK。
- 同步调用覆盖查询参数、请求头、JSON、表单、原始字节、流、multipart、结构化响应和下载。
- 2.0 发布前直接移除旧业务快捷方法和非出站能力。
