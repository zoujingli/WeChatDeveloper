# 问题分流标签

工程技能使用五种固定角色描述 Issue 的处理状态。本文件把这些标准角色映射到当前 GitHub 仓库中的实际标签。

| Matt 技能标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或判断 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到标准角色时，必须使用表中对应的 GitHub 标签。若仓库以后调整标签词汇，只修改右侧映射，不修改技能使用的标准角色。
