# 文档中心

WeChatDeveloper 2.0 是面向微信与支付宝官方 API 的协议层 PHP SDK。本页按使用目标组织文档；首次接入建议依次阅读配置、公开 API 和目标平台指南。

## 首次接入

1. 从项目根目录的 [README](../README.md) 完成安装和最小调用。
2. 阅读[配置与凭证](configuration.md)，准备应用标识、密钥、证书和平台信任材料。
3. 通过[公开 API 速查](api.md)选择根客户端工厂、通用调用方法或专用能力。
4. 按接入平台继续阅读对应指南。
5. 使用[异常](exceptions.md)建立统一捕获、精确告警和重试边界。

## 平台指南

| 目标 | 文档 | 主要内容 |
| --- | --- | --- |
| 微信公众平台、小程序、服务平台 | [微信平台](wechat.md) | access token、授权地址、消息安全模式、媒体、第三方平台授权方调用 |
| 微信支付 APIv3 | [微信支付](payments.md) | 商户请求签名、平台响应验签、通知验签解密、账单下载 |

## 文档边界

- `README.md` 只承担项目定位、最短上手路径和全局导航。
- `docs/*.md` 面向 SDK 使用者和贡献者，每个主题只保留一份权威说明。
- `docs/agents/*.md` 面向开发代理，定义问题跟踪、领域文档和开发流程，不属于 SDK 使用手册。
- `CONTEXT.md` 与 `docs/adr/` 按需记录项目术语和少量长期架构决策，不为补齐目录而创建空文件。
